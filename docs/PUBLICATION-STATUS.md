# وضعیت عمومی‌شدن مخزن

تاریخ: ۲۰۲۶-۱۰-۱۸

این سند، بررسی تاریخی پیش از عمومی‌شدن مخزن را ثبت می‌کند. وضعیت انتشار نسخهٔ ۴.۶.۰ و لینک‌های فعلی در [README](../README.md) و [گزارش انتشار](RELEASE-4.6.0-VERIFICATION.md) هستند.

مخزن `sajjadshadloo/Notepad` با درخواست صاحب پروژه از Private به Public تغییر کرد:

https://github.com/sajjadshadloo/Notepad

## بررسی پیش از تغییر

- دریافت آخرین شاخه‌ها و tagهای origin و بررسی همهٔ ۴۹ commit قابل دسترس در checkout.
- اسکن تاریخچه و ۱۷۷ فایل فعلی با Gitleaks 8.30.1 و قواعد پیش‌فرض، بدون پنهان‌کردن موارد با کامنت allow؛ نتیجهٔ هر دو اسکن صفر یافته بود. فایل دانلودشدهٔ ابزار با checksum انتشار رسمی تطبیق داده شد.
- بررسی نام فایل‌های حساس در تاریخچه؛ فایل تنظیمات شخصی، کلید خصوصی، لاگ، دیتابیس و بکاپ حساس در این فهرست پیدا نشد. تنها فایل `data/today.md` پیدا‌شده متن تست داشت و در تاریخچهٔ شاخه‌های remote نبود.
- اسکن متن commitها، شرح Releaseها و metadata مسئله‌ها؛ یافته‌ای ثبت نشد. مخزن مسئله، wiki، discussion و artifact اجرای GitHub نداشت. لاگ اجرای قدیمی با HTTP 410 در دسترس نبود و بررسی محتوایش انجام نشد.
- آرشیو portable نسخهٔ ۲.۶ شامل ۲۱۴ عضو بود؛ نام حساس یا فایل تنظیمات/یادداشت کاربر در آن پیدا نشد و فایل‌های متنی همراه نیز بدون یافته بودند. تعریف بسته‌بندی tagهای ۲.۵ و ۲.۶ فقط assets را به‌عنوان دادهٔ همراه معرفی می‌کند. این بررسی معادل تحلیل یا اجرای کامل همهٔ باینری‌های قدیمی نیست.
- گزارش‌های خام بررسی فقط در مسیر نادیده‌گرفته‌شدهٔ `.smoke-data/publication-audit/` نگهداری شدند. این اسکن‌ها تضمین مطلق نبود هر نوع اطلاعات خصوصی نیستند.

## تأیید نتیجه در زمان عمومی‌شدن مخزن

- GitHub CLI وضعیت `PUBLIC` را گزارش کرد.
- درخواست HTTPS مستقل و بدون توکن به API مخزن، پاسخ 200 و `private: false` گرفت.
- endpoint آخرین Release بدون احراز هویت پاسخ 200 داد؛ آخرین نسخهٔ عمومی در آن مرحله `v2.6.0` بود. Release قدیمی `v2.5.0` نیز با عمومی‌شدن مخزن قابل دسترسی شد.
- در آن مرحله تغییرات محلی commit/push نشده بودند و Release تازه‌ای ساخته نشده بود. انتشار بعدی ۴.۶.۰، با درخواست جداگانهٔ صاحب پروژه، در گزارش فعلی انتشار ثبت می‌شود.

نسخهٔ مجهز به updater یعنی ۴.۶.۰، Release قدیمی ۲.۶ را جدیدتر تشخیص نمی‌دهد و آن را به‌عنوان به‌روزرسانی پیشنهاد نمی‌کند.
